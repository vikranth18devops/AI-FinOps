# 13 - One-Click GCP Deployment Script

## 📌 1-Click Automated Script

Deploy the full microservices stack to GCP GKE with one command:
```bash
./deploy-gcp.sh
```

To run all 3 microservices locally simultaneously:
```bash
./start_local.sh
```
