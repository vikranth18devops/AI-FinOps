## 📌 1-Click Automated Script

Deploy the full microservices stack to GCP GKE with one command:
```bash
./deploy-gcp.sh
```

To run all 3 microservices locally simultaneously on dedicated custom ports:
```bash
./start_local.sh
```

- ⚙️ **Backend API**: `http://localhost:8080`
- 📱 **Frontend Dashboard**: `http://localhost:3000`
- 🚀 **UI_Script Provisioner**: `http://localhost:8585`
