# 09 - One-Click Azure Deployment Script

## 📌 1-Click Automated Script

Deploy the full microservices stack to Azure AKS with one command:
```bash
./deploy-azure.sh
```

To run all 3 microservices locally simultaneously:
```bash
./start_local.sh
```
