# 09 - One-Click AWS Deployment Script

## 📌 1-Click Automated Script

Deploy the full microservices stack to AWS EKS with one command:
```bash
./deploy-aws.sh
```

To run all 3 microservices locally simultaneously:
```bash
./start_local.sh
```
